# 代码结构

## 客户端

- `TMK-Client/main.go`：Wails 应用入口、服务注册和窗口生命周期编排。
- `TMK-Client/tray.go`：系统托盘菜单和快捷操作编排。
- `TMK-Client/internal/client/session`：实时 WebSocket 会话、历史 REST API 和协议 DTO。
- `TMK-Client/internal/client/capture`：麦克风/WASAPI 采集，并通过注入的音频发送函数连接会话服务。
- `TMK-Client/internal/client/settings`：用户设置持久化。
- `TMK-Client/internal/client/export`：TXT/SRT 导出。
- `TMK-Client/internal/client/window`：主窗口和悬挂字幕窗口控制。
- `TMK-Client/internal/client/runtime`：测试/生产环境选择和后端地址构造。
- `TMK-Client/internal/platform`：快捷键等操作系统适配。
- `TMK-Client/internal/audio`：底层音频采集实现。

客户端业务服务不再通过根目录全局变量互相调用，入口只负责组装依赖；Wails 绑定按 Go 包路径生成。

## 服务端

- `internal/server/router.go`：路由注册、数据库和翻译服务初始化。
- `internal/server/system_handlers.go`：健康检查、语言和音频设备接口。
- `internal/server/session_handlers.go`：会话创建、查询和停止。
- `internal/server/history_handlers.go`：历史查询和删除。
- `internal/server/summary.go`：AI 摘要、会话主题生成和异步任务。
- `internal/server/translate_handler.go`：单次翻译 HTTP 接口。
- `internal/server/websocket_handler.go`：WebSocket 升级和 SessionActor 创建。
- `internal/server/session_actor.go`：单会话状态机和消息写入。
- `internal/server/translation_scheduler.go`：翻译队列、final barrier 和持久化。
- `internal/server/factories.go`：ASR/翻译实现选择。
- `internal/server/middleware.go`：HTTP 中间件。

路由层只负责注册和依赖初始化；业务处理器、实时管线、供应商工厂和中间件分别维护，后续可独立测试和替换。
