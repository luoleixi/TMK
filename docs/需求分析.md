# 需求分析

## 用户需求

TMK 是一个实时同声传译桌面应用，用户期望客户端提供以下能力：

- 在主界面选择源语言与目标语言
- 自由选择麦克风或系统音频作为输入源
- 两种使用模式：**实时翻译**（即时显示 ASR 识别文本和翻译结果）和**历史记录**（回溯查看过往会话的翻译记录）
- 流式传输，ASR 识别完成后即时推送结果

## 业务流程

### 实时翻译

```
用户选择语言和音频源 → 点击"开始翻译"
  → 客户端创建会话（POST /api/v1/sessions）
  → 客户端建立 WebSocket 连接（/api/v1/interpret?session_id=xxx）
  → 客户端发送 start 消息，服务端初始化 ASR 引擎
  → 客户端开始音频采集，PCM 帧通过 WebSocket 持续发送
  → ASR 实时识别 → 翻译引擎翻译 → 服务端推送 transcript + translation
  → 客户端实时展示源文本和译文
  → is_final 为 true 时追加记录到当前会话列表，并持久化到 MySQL
  → 用户可暂停/继续/停止会话
```

### 历史记录

```
用户切换到"历史记录"标签页
  → 客户端请求 GET /api/v1/history（支持分页和语言/日期筛选）
  → 展示会话列表（语言对、记录数、时间）
  → 点击某条会话展开详情
  → 客户端请求 GET /api/v1/history/{id}
  → 展示该会话下所有翻译记录（源文本 → 译文）
```

## API 接口

**Base URL**: `http://{host}:{port}/api/v1`

### REST 接口

| 方法 | 端点 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查，返回 status、version、各服务可用性 |
| GET | `/api/v1/languages` | 支持的语言列表（zh/en/ja/ko/fr/de/es/ru） |
| POST | `/api/v1/sessions` | 创建会话，body: `source_lang`, `target_lang`, `input_type` |
| GET | `/api/v1/sessions/{id}` | 查询会话详情及状态 |
| POST | `/api/v1/sessions/{id}/stop` | 结束会话（status → completed） |
| POST | `/api/v1/translate` | 单句翻译，body: `text`, `source_lang`, `target_lang` |
| GET | `/api/v1/history` | 历史会话列表，支持 `offset`, `limit`, `source_lang`, `target_lang`, `date_from`, `date_to` |
| GET | `/api/v1/history/{id}` | 历史会话详情，含全部翻译记录 |

### WebSocket: `/api/v1/interpret`

**客户端 → 服务端**

| 消息类型 | 说明 |
|---------|------|
| `start` | 启动识别管线，服务端初始化 ASR 引擎 |
| `audio`（二进制） | PCM 16kHz 16bit 单声道 LE 音频帧 |
| `ping` | 心跳 |
| `stop` | 停止会话，关闭连接 |

**服务端 → 客户端**

| 消息类型 | 说明 |
|---------|------|
| `started` | 管线就绪，含 `timestamp_ms` |
| `transcript` | ASR 识别结果 `{text, is_final, timestamp}` |
| `translation` | 翻译结果 `{text, is_final, timestamp}` |
| `pong` | 心跳响应 |
| `stopped` | 会话已停止 |
| `error` | 错误信息 |

**管线流程**: `PCM 音频帧 → ASR (paraformer-realtime-v2) → transcript → Translator (qwen-turbo) → translation → 客户端`

### 数据模型

**Session**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string (UUID) | 会话唯一标识 |
| user_id | string (UUID) | 会话所属用户 |
| source_lang | string | 源语言代码 |
| target_lang | string | 目标语言代码 |
| input_type | string | 音频源类型（system_audio / microphone） |
| status | string | ready → active → completed / error |
| record_count | int | 翻译记录数 |
| created_at | time | 创建时间 |
| ended_at | time | 结束时间（可空） |

**Record**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 自增主键 |
| session_id | string | 所属会话 ID |
| sequence | int | 会话内序号 |
| source_text | string | ASR 识别原文 |
| translated_text | string | 翻译后文本 |
| confidence | float | 置信度（预留，当前为 0） |
| audio_duration_ms | int | 音频时长（预留，当前为 0） |
| created_at | time | 创建时间 |

## 客户端/服务端职责边界

| 职责 | 客户端 | 服务端 |
|------|--------|--------|
| 音频设备枚举与采集 | WASAPI 环回 / WaveIn 麦克风 | — |
| PCM 音频发送 | WebSocket 二进制帧 | — |
| ASR 语音识别 | — | 阿里云百炼 paraformer-realtime-v2 |
| 文本翻译 | — | 阿里云百炼 qwen-turbo |
| 会话生命周期管理 | 发起创建/停止 | 状态流转 + 持久化 |
| 翻译记录持久化 | — | MySQL（本地测试可使用 SQLite） |
| 身份与权限 | 登录并携带令牌 | 密码校验、令牌轮换、RBAC、资源所有权检查 |
| UI 展示（字幕 + 历史） | React | — |
| 历史记录查询 | HTTP 请求 | 分页筛选 + 关联查询 |
